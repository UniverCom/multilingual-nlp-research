# Multilingual NLP Architectures: A Linguistic Analysis

A technical research report examining four multilingual NLP architectures; 
**mBERT, XLM-R, ByT5, and GPT** from a computational linguistics perspective.

The report covers, for each model:
- Tokenization strategy (WordPiece, BPE, byte-level) and its morphological implications
- Pre-training, fine-tuning, and cross-lingual transfer (zero-shot / few-shot)
- API availability with runnable code examples

The final sections move beyond architecture into a broader question: whether 
statistical, correlation-based systems can achieve genuine *understanding*, or 
remain sophisticated imitation. This is examined through the arbitrariness of 
linguistic signs, the Chinese Room argument, and a comparison between human 
language acquisition (Language Acquisition Device, principles & parameters) and 
machine learning paradigms.
